# Align durable control planes with prefix-stable local trios

**BLUF:** The durable multi-agent pattern that fits a bedside CDSS is a fixed retrieve→rerank→gate→synthesise workflow inside a checkpointed control plane (Temporal activities, LangGraph `durability="sync"`, or Vercel `step` boundaries), with every chart write keyed by a stable idempotency token minted *before* the side effect and with CDS Hooks 2.0.1 cards—not free prose—as the outward contract ([CDS Hooks STU2](https://cds-hooks.hl7.org/STU2/), [Temporal idempotency](https://temporal.io/blog/idempotency-and-durable-execution)). KV prefix reuse is a separate optimisation: every production cache matches **exact rendered bytes** in order **tools → system → messages**, so six specialists hit only when EMR, Guideline, Safety, Quality, Critic, and Synthesis share that prefix and diverge afterward ([Anthropic prompt caching](https://platform.claude.com/docs/en/build-with-claude/prompt-caching), [vLLM APC](https://docs.vllm.ai/en/stable/features/automatic_prefix_caching/)). On a **48 GB** Apple Silicon Mac the **~17 GB** weight envelope for MedEmbed-large-v0.1, bge-reranker-v2-m3, and MedSwin **7B** DaRE-TIES-KD fits comfortably, but this repository still serves the generator on **CPU FP32**, re-encodes every HTTP prompt, and can bind context to **512** tokens via the DaRE tokenizer—while multi-agent calls inject **~14.4k characters** of passages per specialist and `system_eval` forces **cloud 1536-d** retrieval against a local generator. Strategic closure means one vector space per index, one generation backend alias in health and chat, MPS or MLX for the 7B path, rerank that cannot fail open silently, compaction that never rewrites the shared prefix, and abstention expressed as **empty `cards`** with contraindications and citation ids kept in checkpointed state—not in summaries alone.

## Durable control planes carry clinical truth; KV caches only save prefill

Industry-facing CDSS wiring in **2025–2026** still centres on **CDS Hooks 2.0.1** plus FHIR Clinical Reasoning artefacts: a client POSTs to `{baseUrl}/cds-services/{service.id}`, must not send null placeholders, and may return an **empty `cards` array** as valid “no guidance”; each emitted card needs `summary`, `indicator` (`info` | `warning` | `critical`), and `source`, with optional suggestions, `systemActions` (auto-apply paths the client may reject), and a feedback endpoint keyed by card `uuid` ([CDS Hooks 2.0](https://cds-hooks.hl7.org/2.0/), [CDS Hooks changelog](https://cds-hooks.hl7.org/changes.html)). FHIR Clinical Reasoning separates sharable knowledge (`Library`, `PlanDefinition`) from per-patient evaluation (`GuidanceResponse`, `$apply` / `$evaluate`) and maps a CDS endpoint to `PlanDefinition` via `cdsHooksEndpoint` ([FHIR Clinical Reasoning](https://hl7.org/fhir/clinicalreasoning-module.html)). **ONC HTI-1** replaced the old CDS certification criterion with **45 CFR 170.315(b)(11)**: certified modules must surface **13 source attributes** for evidence-based decision support interventions and **31** for predictive DSIs, with FAVES transparency duties and, from **1 January 2026**, demographic-use disclosure tied to **USCDI v3** ([ONC DSI resource guide](https://healthit.gov/wp-content/uploads/2024/05/DSI-Criterion-Resource-Guide_508.pdf)). MedSwin after the Bedrock cutover already implements discovery and a `patient-view` evidence service with card disclaimers, but it still omits `GuidanceResponse`, does not encode drug–drug or drug–allergy rules as computable artefacts, and keeps human review in prose rather than in card `detail` with passage ids—the gap the earlier architecture audit named between abstention instinct and inspectable contract.

Durable agent runtimes address a different failure mode than model serving. **Temporal** keeps workflow code deterministic and runs LLM and tool work in **activities** whose results are recorded in event history—retries are **at-least-once** by default, and the documented idempotency key when the domain offers none is **`workflowRunId + activityId`**, constant across retries ([Temporal durable AI agent](https://learn.temporal.io/tutorials/ai/durable-ai-agent/), [Temporal Pydantic AI](https://temporal.io/blog/build-durable-ai-agents-pydantic-ai-and-temporal)). **LangGraph** persists super-step checkpoints under `thread_id`; a retry or `interrupt()` **re-executes the whole node from its first line**, so side effects before the interrupt must be idempotent or live inside already-completed tasks, and **`durability="sync"`** persists before the next step starts ([LangGraph checkpointers](https://docs.langchain.com/oss/python/langgraph/checkpointers), [LangGraph fault tolerance](https://docs.langchain.com/oss/python/langgraph/fault-tolerance), [LangGraph interrupts](https://docs.langchain.com/oss/python/langgraph/interrupts)). **Vercel Workflow** splits `'use workflow'` coordination from `'use step'` side effects; wrapping an entire agent loop in one step repeats the loop on interruption, whereas one step per model call and per external tool preserves progress, and `getStepMetadata().stepId` is the documented idempotency handle ([Workflow SDK idempotency](https://workflow-sdk.dev/docs/foundations/idempotency), [Vercel durable agents](https://vercel.com/kb/guide/durable-ai-agents)). The inference for CDSS is explicit: **checkpoint structured specialist JSON in the control plane** even when vLLM, SGLang, llama.cpp, or MLX reuse KV for a shared prefix ([vLLM APC](https://docs.vllm.ai/en/stable/features/automatic_prefix_caching/)); **do not** treat token generation as the idempotent clinical write—the EHR mutation, feedback POST, or chart append is. MedSwin’s full pipeline still runs five claim agents sequentially in one FastAPI process with **no supervisor cancel**, trace writes on full/two-stage paths **not wrapped** against Mongo failure, and **no** stable idempotency keys on any future write path—while it already embodies the right *clinical* graph shape (retrieve, rerank, gate, then synthesise) that Anthropic’s agent guidance recommends when subtasks are known ([Building effective agents](https://www.anthropic.com/research/building-effective-agents)). The strategic move is not to bolt a seventh orchestration framework onto prose chat, but to persist the evidence bundle, gate decision, and structured specialist claims **before** committing the HTTP response, and to map insufficient evidence to **empty `cards`** or a warning card whose detail lists facet failures and passage ids, matching CDS Hooks’ abstention semantics without abandoning the existing gate.

| Layer | Industry pattern | MedSwin today | Strategic alignment |
| --- | --- | --- | --- |
| Outward API | CDS Hooks cards + feedback | `cds-services/medswin-evidence` without full ONC attribute record | Map gate pass/fail to cards; store source metadata beside traces |
| Deterministic rules | CQL / `PlanDefinition` | RAG-only contraindications | Rules engine for DDI/allergy; LLM for narrative synthesis |

## Prefix-stable fan-out and compaction budgets protect citations in short windows

Across cloud and local engines, **prompt caching is longest-prefix equality on rendered bytes**. Anthropic’s contract states render order **tools, then system, then messages**; a change at byte *N* invalidates every breakpoint at or after *N*, and **tool lists must be serialised deterministically** (`sort_keys=True`, stable ordering—`json.dumps` without sorting is listed as a silent miss) ([Anthropic prompt caching](https://platform.claude.com/docs/en/build-with-claude/prompt-caching), [Anthropic prompt-caching skill](https://github.com/anthropics/skills/blob/main/skills/claude-api/shared/prompt-caching.md)). OpenAI’s default cache for GPT-5.6+ requires a **1,024-token** visible prefix; explicit breakpoints bill writes at **1.25×** (30-minute) or **2.5×** (12-hour) input and reads at **0.1×** on most models ([OpenAI prompt caching](https://developers.openai.com/api/docs/guides/prompt-caching)). Amazon Bedrock combines implicit best-effort reuse with model-specific explicit checkpoints; minima span **512–4,096** cumulative tokens, TTLs often **5 minutes** refreshed on hit, and **cache entries are local to the server that wrote them** ([AWS Bedrock prompt caching](https://docs.aws.amazon.com/bedrock/latest/userguide/prompt-caching.html)). On device, **vLLM automatic prefix caching** hashes chained blocks (default **16-token** blocks in 2025 documentation) and reuses only complete blocks—PrefixBench-H100 reports **2.48×** p50 TTFT improvement at a **2,048-token** prefix at concurrency 1, rising toward **6.51×** at **8,192** tokens, but under load the ranking against TensorRT-LLM inverts ([PrefixBench-H100](https://arxiv.org/html/2609.19657), [vLLM anatomy](https://vllm.ai/blog/2025-09-05-anatomy-of-vllm)). **llama.cpp `llama-server`** can reuse KV within a slot when prompts share a prefix, yet **`-c` divided by `-np`** shrinks per-slot context—six parallel slots on a **2,048** window yields roughly **341 tokens per slot**, so sequential specialists on **`-np 1`** is the realistic local pattern ([llama.cpp discussion 13606](https://github.com/ggml-org/llama.cpp/discussions/13606)). **MLX-LM** offers `cache_prompt`, `trim_prompt_cache`, and **RotatingKVCache** (default **4k** in a 2025 Apple Silicon serving comparison); on-disk prompt caches can retain sensitive tokens and belong only on de-identified prefixes ([MLX cache_prompt](https://github.com/ml-explore/mlx-lm/blob/main/mlx_lm/cache_prompt.py), [arXiv 2511.05502](https://arxiv.org/pdf/2511.05502)).

The engineering design that follows is a **shared specialist prefix**—canonical tool catalogue sorted by name, safety and output schema, short guideline index—then one breakpoint or block boundary, then role name, patient snapshot, retrieved spans, and prior specialist **structured verdicts**, never five full transcripts pasted into every call. **Compaction must not rewrite that prefix**: summarisation and dropped turns append or replace **suffix only**; middle rewrites are full-prefill misses on vLLM and Anthropic alike ([vLLM APC](https://docs.vllm.ai/en/stable/features/automatic_prefix_caching/)). Context-window science reinforces clinical placement: Hsieh et al. (2025) report **lost-in-the-middle** strongest when input occupies **≤50%** of the window; beyond that, primacy falls and **recency dominates**, so on a **2,048-token** MedSwin backbone the risky band is roughly the first **1,024** tokens of narrative filler, while decisive contraindication lines and citation stubs should sit in the **suffix** ([Positional biases](https://arxiv.org/abs/2508.07479), [Lost in the Middle](https://aclanthology.org/2024.tacl-1.9/)). Agent-memory systems with measured token cuts—**Acon** (~**26–54%** peak token reduction on agent benches), **HiAgent** (roughly twofold success gains on long horizons), **Virtual Context** (raw tail preserved, segment summaries ~**15%** of source when utilisation passes **70%**)—support a **three-store** pattern: **Store A** (checkpointed full JSON, FHIR snippets, chunk ids outside the model), **Store B** (prompt suffix: verbatim contraindications, citation stubs, active subgoal), **Store C** (short summaries of finished subgoals, never the sole copy of a medicine or allergy) ([Acon](https://arxiv.org/html/2510.00615v1), [HiAgent](https://aclanthology.org/2025.acl-long.1575/), [Virtual Context](https://virtual-context.com/paper/)). MedSwin already packs evidence to **`TOKEN_BUDGET_B` default 1800** using **tiktoken `cl100k_base`**, not the Llama tokenizer, while specialists still receive up to **`AGENT_PASSAGE_LIMIT=12`** passages of **`AGENT_PASSAGE_MAX_CHARS=1200`** each—orders of magnitude more text than a **2048** (or **512-enforced) window can admit in one `serve-medswin-llm.py` call, which **fail-closes with HTTP 422** rather than truncate (verified in `scripts/serve-medswin-llm.py` and `app/agents/base.py`). Cloud calls remain **stateless** with no recorded `cached_tokens` or pinned prefix; the **600-second floor** on HTTP 429 backoff can stall bedside traffic even when `Retry-After` is shorter—a policy gap Kollab-style short honouring would close without copying ten-minute sleeps.

## Structured output tiers separate syntax from semantic joins to the retrieval store

**The Constraint Tax** (May 2026) quantifies why CDSS cannot trust schema validity alone on small models: on sub-3B suites, hard schema decoding raised validity from **61.5%** to **100%** while answer accuracy fell from **19.7%** to **11.0%**, and wrong-but-valid outputs rose toward **89%**; on a **1.5B** calendar tool task, executable accuracy dropped **43.5 points** (91.5% → 48.0%) under hard schema versus prompt JSON, recoverable by **reason-free, constrain-late** re-serialisation ([The Constraint Tax](https://arxiv.org/html/2605.26128)). No paper in the research pass measures a **7B medical Llama**, but the failure mode transfers: **valid JSON with the wrong drug, wrong abstain bit, or citation id the retriever never returned**. JSONSchemaBench shows grammar backends differ in compile, over-constraint, and under-constraint failure rates across real schemas ([JSONSchemaBench](https://arxiv.org/html/2501.10868v1)); Amazon Nova’s constrained decoding post claims **>95%** fewer tool-use errors versus a prompted path but warns accuracy falls as schemas grow complex—syntax gain, not clinical correctness ([AWS Nova structured outputs](https://aws.amazon.com/blogs/machine-learning/structured-outputs-with-amazon-nova-a-guide-for-builders/)).

The recommended **two-tier** design maps cleanly to MedSwin’s split stack. **Local MedSwin 7B:** step one is a short free-text or lightly prompted judgement with explicit abstain language; step two is a deterministic packager or a tiny constrained decode over **enums and ids only**—`abstain`, CDS `indicator`, `citation_ids[]`, `contraindication_ids[]`—with an ordinary-code **join** that drops any id absent from Store A before emitting a card ([CDS Hooks 2.0](https://cds-hooks.hl7.org/2.0/)). **Cloud Bedrock Luna / frontier:** native tool calling plus provider constrained decoding carries richer narrative `summary` and `detail`, but the same join runs in a checkpointed activity; **`abstain: true`**, failed citation join, or a Safety id missing in Synthesis triggers **`interrupt()`** or empty `cards`, not a second sample. **One tool catalogue** sorted by name is shared across all specialists; role-specific behaviour belongs in messages **after** the cache breakpoint, because adding a Safety-only tool mid-prefix invalidates cache on Anthropic, Bedrock, and OpenAI ([AWS Bedrock prompt caching](https://docs.aws.amazon.com/bedrock/latest/userguide/prompt-caching.html)). Deterministic JSON serialisation should feed **both** the model tool schema and the CDS wire format, which forbids null optionals—so audit bytes and cache bytes cannot drift. Neither model tier should POST orders; **`systemActions`** remain client-controlled.

## Apple Silicon can host the research trio while the repo still forfeits Metal and prefix reuse

**MedSwin/MedSwin-DaRE-TIES-KD-0.7** is a standard **LLaMA-7B** causal LM (**32** layers, hidden **4096**, **vocab 32001**, RoPE **θ=10000**, config **`max_position_embeddings=2048`**, Apache-2.0), a **DaRE+TIES** merge of SFT, KD, and **medalpaca/medalpaca-7b** ([DaRE config](https://huggingface.co/MedSwin/MedSwin-DaRE-TIES-KD-0.7/resolve/main/config.json), [merge README](https://huggingface.co/MedSwin/MedSwin-DaRE-TIES-KD-0.7/raw/main/README.md)). **`abhinand/MedEmbed-large-v0.1`** is a **1024-d** BERT bi-encoder with **CLS + L2**, **512** positions, fine-tuned from BGE-large ([MedEmbed config](https://huggingface.co/abhinand/MedEmbed-large-v0.1/resolve/main/config.json)). **`BAAI/bge-reranker-v2-m3`** is an XLM-RoBERTa cross-encoder with **`max_position_embeddings=8194`**—pair cost dominates latency if passages approach that ceiling ([bge-reranker config](https://huggingface.co/BAAI/bge-reranker-v2-m3/resolve/main/config.json)). On **M5 Pro 48 GB**, third-party estimates place **~40 GB** usable for weights and KV after OS reserve, against **~17 GB** combined cited weight files—headroom exists for FP16 MPS inference and modest KV ([CanItRun M5 Pro 48GB](https://canitrun.dev/gpus/m5-pro/)), though **no published on-device benchmark** of all three together was found.

The repository’s **live local generator path contradicts that hardware envelope**. `scripts/serve-medswin-llm.py` sets **`torch.float32` on CPU** when CUDA is absent—**no MPS branch**—while `scripts/smoke_medswin_backbone.py` already demonstrates **MPS + FP16** ([PyTorch MPS](https://pytorch.org/docs/stable/notes/mps.html)). **MLX is not integrated**; external MLX or llama.cpp/Ollama behind the existing OpenAI-shaped URL remains greenfield. Within a single `generate()` call, Hugging Face maintains **`past_key_values`** by default, but the server **re-tokenises the full prompt on every HTTP request** and exposes no static/prefix cache API ([HF generation docs](https://huggingface.co/docs/transformers/main/en/kv_cache)). MedEmbed and bge-reranker **do** use `inference_device()` → **MPS** when available—a split stack where retrieval is Metal-accelerated and synthesis is not. Separately, the DaRE **`tokenizer_config.json`** sets **`model_max_length: 512`** with **BOS and EOS both `</s>`** and **no `chat_template`**; the server takes the **minimum** of config and tokenizer limits, so the **512 cap can bind** overflow checks unless operators override—colliding with multi-agent passage injection and **`MEDSWIN_MAX_NEW_TOKENS` default 1024** ([tokenizer_config](https://huggingface.co/MedSwin/MedSwin-DaRE-TIES-KD-0.7/raw/main/tokenizer_config.json)). Prompt fallback is raw **`ROLE: content`** lines, not MedAlpaca templating—reproducibility and cloud comparison drift.

**Local three-model operation** further depends on wiring absent from `start-local.sh`: configured **`EMBEDDING_URL` :8005** and **`RERANKER_URL` :8004** have **no standalone serve scripts**; only **`serve-medswin-llm.py` on :8000** and the API on **8100** exist. `EmbeddingClient` can **fall back in-process** to `ModelManager` when HTTP fails, but **`RerankerClient` has no fallback**—`HybridRetriever` **returns un-reranked order** on error (`app/services/adapters/reranker.py`, `app/retrieval/hybrid.py`). **`CLOUD_MODE=true`** skips downloading/loading local embedder weights; **`system_eval`** forces **`CLOUD_MODE=true`** and health checks for **Foundry-era embed/rerank strings**, drifting from Bedrock’s **`global.cohere.embed-v4:0`** and **`cohere.rerank-v3-5:0`**. TREC-CDS prep embeds with **`active_embedding_model()`** (cloud **1536-d**); querying that index with MedEmbed **1024-d** vectors is a different space—`/health` correctly degrades when provenance disagrees, but eval matrices never exercise the local retrieval plane. **Strategic runtime improvements** read as a ordered bundle: fix downloads and pooling to real MedEmbed semantics; rebuild **1024-d** HNSW with **`embedding_space` provenance**; point embed HTTP at in-app batch routes or a thin proxy; add rerank in-process fallback or a real :8004 handler; patch **`serve-medswin-llm.py` for MPS FP16** (or route generation through MLX/`cache_prompt` for shared agent prefixes on de-identified instructions only); raise or override **`model_max_length` to 2048** consistently with RoPE config; align **`GENERATION_BACKEND` aliases** in `/pipelines/ready` and chat; shrink agent envelopes or gate specialist calls when tiktoken evidence plus system overhead exceeds window; update **`system_eval` contracts** to Bedrock ids and add a **`medswin_local + MedEmbed + bge`** profile; cap bge pair length far below **8192** in production loops.

## Conclusion

The research sharpens a distinction the earlier CDSS architecture report implied but did not separate from serving economics: **durable orchestration and KV prefix reuse optimise different layers**. Checkpoints and idempotent activities protect clinicians from duplicate writes and lost abstention decisions; prefix caching and `trim_prompt_cache` only reduce prefill latency when bytes are stable and specialists fan out from one suffix. MedSwin’s clinical instinct—gate before synthesise, traces with passage ids, Bedrock Luna with bounded output—is already aligned with the control-plane half of that picture; the remaining distance is **identity and measurement**: one embedder dimension per index, one backend string in health and chat, structured cards with the same canonical JSON the cache sees, and eval harnesses that can run the **7B + MedEmbed + bge** cell on this Mac without cloud retrieval pretending to be local. Until the **512-token tokenizer floor** and **14k-character agent MAC** collide with a **2048** Llama table, faster Bedrock or Metal inference mainly accelerates mismatched or fail-closed requests. Fixing window accounting, prefix-stable multi-agent prompts, and rerank fail-open behavior is the prerequisite that makes KV optimisation and Apple Silicon capacity matter for CDSS quality—not just for tokens per second.
